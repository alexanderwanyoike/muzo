# Muzo 0.0.1

Initial Electron desktop release.

## Music libraries

- Add filesystem folders, scan recursively and keep music in sync while Muzo is open and at startup.
- Connect Dropbox with secure credential storage, browse and select multiple folders, sync libraries and play cloud tracks.
- Search sources, refresh or remove a source, and keep unavailable playlist entries identifiable after removal.
- Read embedded metadata, edit catalogue overrides and record play history.

## Listening and playlists

- Play local and Dropbox tracks with transport controls, seeking and volume.
- Create playlists, add songs, reorder/remove entries and play queues with previous/next and automatic advancement.
- Preserve repeated tracks as distinct queue entries and recover from failed playback sources.
- Display embedded album artwork in songs, playlists, the transport and the sidebar, with persistent thumbnail caching.

## Desktop workspace

- Studio, brushed aluminium, warm paper, carbon fibre, walnut and porcelain materials, each with light/dark modes and ten accent colours.
- Matching searchable Sources and Playlists panels with a shared persistent, keyboard-accessible resize divider.
- Consistent Settings section widths, headers, spacing, fields and actions at desktop and minimum window sizes.
- Flat blue/black waveform icons with a pixel-aligned Linux panel variant, and native desktop packaging for Linux, Windows and macOS.

## Verification

- 337 maintained tests pass, including 48 native Settings layout scenarios.
- Formatting, typed Airbnb lint, strict TypeScript, build, package and Linux distributable checks pass.
- Native CI covers icons, profile identity, artwork caching and Settings layout on Windows and macOS.
- Feature PRs have completed their initial review and re-review cycles. Manual desktop checks are documented in docs/testing/desktop-ui-smoke-test.md.
