# Muzo 0.0.4

This patch fixes restarting Muzo after a Linux AppImage update.

## What changed

- The player starts the updated AppImage directly during final shutdown, preserving its launch arguments.
- Updates keep the existing AppImage filename and location, so menu entries and dock pins continue to point to the same file.
- A failed launch displays a message with the installed file to reopen.
- Linux installer CI now exercises an actual AppImage updating and reopening, including its saved library and menu entry.

## Updating

If you use Muzo 0.0.3, download this update from the notice at the bottom of the sidebar and choose Restart to install. If Muzo closes without reopening, open your existing AppImage again. Version 0.0.3 contains the old restart code; the replacement file is already installed. This patch fixes subsequent update restarts.

You can also download the Linux x64 AppImage directly. Windows x64 and macOS installers for Apple silicon and Intel are included with matching versions. Unsigned macOS builds continue to use manual downloads. These preview builds are unsigned and macOS builds are not notarized.

Your libraries, playlists, cached artwork and Dropbox credentials continue to use the existing Muzo profile. The complete release includes SHA256SUMS, its distribution manifest and Windows/Linux update metadata.
