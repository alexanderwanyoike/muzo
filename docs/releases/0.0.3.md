# Muzo 0.0.3

This release improves Linux desktop integration, the mini player and application updates.

## What changed

- Linux AppImages add Muzo to the application menu on first launch with its blue waveform icon. You can then pin it through your desktop's normal controls. Moving the AppImage refreshes its shortcut; old Cinnamon shortcuts to temporary mounts are repaired.
- The mini player has straight edges. Its icon-only toggle sits at the top right of the full player, above volume.
- A newer release appears at the bottom of the sidebar. Click to download, keep listening, then choose Restart to install when ready. Closing Muzo normally does not install a pending update.
- Windows installers and Linux AppImages can update in place. AppImages keep their existing filename and location so menu and dock entries continue to work.

## Installing

Download the Windows x64 installer, Linux x64 AppImage, or macOS disk image for Apple silicon or Intel.

If you use v0.0.2, install v0.0.3 manually once to enable future update notices. Unsigned macOS builds open the release page for manual installation. These preview packages remain unsigned and macOS builds are not notarized.

Each release includes SHA256SUMS, the distribution manifest and Windows/Linux update metadata. Your music catalogue, cached artwork and Dropbox credentials continue to use the existing Muzo profile.
